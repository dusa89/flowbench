The short version

Owner-operator who wants it cheap and hands-off: Make's visual builder and generous free plan (1,000 credits/mo) get a working automation live fastest, and paid tiers start low. Team that will scale to heavy volume or cares about data control: n8n's self-host option and flat-per-user cloud pricing beat Make's per-operation math once workflows get busy — and you can run it on your own server if you want zero vendor lock-in. Zapier is shown as the benchmark (7,000+ integrations, shallowest learning curve) but is the priciest at volume; it is not an affiliate anchor here because it has no public affiliate program. The expensive mistake is over-automating before you have the workflow written down on paper — automate the process you already do every week, nothing else.

How the billing math differs

The billing unit is the real comparison, not the brand name. Make bills in credits (renamed from "operations" in Aug 2025) — most actions cost 1 credit. Zapier bills in tasks — each action step in a zap is a task, and multi-step zaps multiply fast (a 6-node flow ≈ 4–5 tasks per run, so 1,000 runs/mo ≈ 5,000 tasks → Pro tier). n8n Cloud bills per-user tiers with generous execution allowances, and self-hosted n8n has $0 marginal runtime on an already-provisioned server — a consultancy running a live demo measured ~1–2h/month of maintenance overhead (dev.to, 2026). Rule of thumb: light volume → Make is cheapest; heavy volume or sensitive data → n8n wins.

Can I really run n8n for free?

Self-hosted n8n is free under its Sustainable Use License for internal business use — you pay for the server (~$5–$20/mo VPS) and your own maintenance time (~1–2h/month per the measured demo). Paid n8n Cloud plans start around €20/mo for people who want zero server duty. Source: dev.to 2026 comparison and 2pizza.team (134 days ago).

Which is easier for a non-technical owner?

Make's visual scenario builder is the gentlest ramp of the two; n8n has the steeper learning curve but more power (custom JavaScript nodes, AI agent workflows). Zapier is shallowest of all but costs the most at volume. Source: dev.to 2026 comparisons, aitoolsnexus (Jun 2026).

Why isn't Zapier a "try it" button here?

Zapier has no public affiliate program (invite-only Experts/Partner program). It's shown as a benchmark because it has the largest integration catalog (7,000+ apps), not because we can earn from recommending it.
